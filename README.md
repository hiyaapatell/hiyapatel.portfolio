# hiyapatel.portfolio

Hiya Patel's F1-themed portfolio website.

## Hosting

The ready-built website is in the repository root. GitHub Pages should publish from `main` and `/(root)`.

## Files

- `index.html` and `assets/`: ready-built portfolio
- `Hiya-Patel-Resume.pdf`: downloadable resume
- `source-code/`: editable React source and build instructions
- `START-HERE.md`: publishing guide
