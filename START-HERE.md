# Publish your Hiya Patel portfolio

## No coding needed

1. Unzip this package on your computer.
2. Create a public GitHub repository. For a free main domain, name it EXACTLY YOUR-USERNAME.github.io (replace YOUR-USERNAME with your GitHub username). If that repository already hosts another website, use a new repository such as hiya-portfolio instead to keep the existing website.
3. In the repository, choose Add file → Upload files. Upload the CONTENTS of this unzipped folder, including index.html and the assets folder. Do not upload the ZIP itself or an enclosing folder. Commit the files. You can upload everything, including source-code; the ready-built website is at the root.
4. Go to Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Wait for GitHub to finish deployment. Settings → Pages will show your working website address. For a main-domain repository it is YOUR-USERNAME.github.io; for another repository it includes /repository-name/.

No custom domain purchase is required. This package has not yet been published to your GitHub account.

## What's inside

- index.html + assets/: ready-built website, no installation required.
- Hiya-Patel-Resume.pdf: your downloadable résumé.
- source-code/: editable React source and build instructions. It does not affect the prebuilt homepage.
- .nojekyll: static hosting marker (may be hidden on your computer).

To make future edits, follow source-code/README.md. Rebuild and replace the website's root files with the new dist/client contents. Opening index.html by double-clicking is not a reliable preview for module-based websites; use GitHub Pages or the source development server.

Visitor notes are saved only in their browser. Use the email contact to receive messages.

Official publishing instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
